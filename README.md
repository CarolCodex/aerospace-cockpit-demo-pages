# 空天战力中枢 · 三维驾驶舱演示

[打开在线演示](https://carolcodex.github.io/aerospace-cockpit-demo-pages/)

基于 React、React Three Fiber 和 Three.js 制作的首页样片。页面使用设计稿示例数据，供视觉和交互演示。

- 六个左侧 Tab 和首页六张卡片均可进入对应模块。
- 点击“驾驶舱总览”、顶部标题或“返回总览”回到首页。
- 地球、云层和卫星实时渲染，支持拖动、暂停、复位和静态背景切换。
- 按 1920 × 1080 大屏比例适配，建议使用电脑浏览器全屏展示。

本仓库保存可直接发布的网页成品。GitHub Pages 从 `main` 分支的根目录发布；更新成品后会自动重新发布。

页面未连接业务系统或后端接口。
