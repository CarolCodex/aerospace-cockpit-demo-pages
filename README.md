# 空天战力中枢 · 三维驾驶舱演示

[打开在线演示](https://carolcodex.github.io/aerospace-cockpit-demo-pages/)

基于 React、React Three Fiber 和 Three.js 制作的驾驶舱交互原型。页面使用设计稿示例数据，供视觉和交互演示。

- 六个左侧 Tab 和首页六张卡片均可进入对应模块。
- 点击“驾驶舱总览”、顶部标题或“返回总览”回到首页。
- 地球、云层和卫星实时渲染，支持有限角度拖动、暂停和巡航模式切换。
- 按 1920 × 1080 大屏比例适配，建议使用电脑浏览器全屏展示。

本仓库保存可直接发布的网页成品。GitHub Pages 从 `main` 分支的根目录发布；更新成品后会自动重新发布。

六个二级页统一采用线上战绩领航的 1076px 内容宽度、标题、卡片和进度条规范；模块徽章按 Figma 413:1190 更新为 120px 圆环、72px 图标、18px 名称。执行雷达、项目罗盘、资金引擎、人才红芯、绩效飞轮已补齐原型业务内容。

页面未连接业务系统或后端接口。快捷任务和督办提醒仅保存于当前浏览器；提醒可复制后发送。原型中的督办事项使用 2026-10-29 的数据快照。
